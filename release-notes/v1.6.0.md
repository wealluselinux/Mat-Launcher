**Mat Launcher 1.6.0**

Settings is now organized into pages, and you can drag apps around on the home screen.

### New
- **Settings in categories.** Settings opens to a list: Updates, Wallpaper, Icons, Home & widgets, Lock screen, Control center, Apps, Permissions, and Setup & about. Tap one to open its own page; Back returns to the list.
- **Drag apps to rearrange them.** In edit mode, long-press an app and drag it to a new spot. Drop it on another app to take its place, or on empty space to send it to the end of that page. Hold it at the left or right edge to move it to another page.
- **Automatic GitHub releases.** Every new version number pushed to GitHub is now built and published as a release with both APKs, so updates reach the in-app updater without a manual step.

### Improved
- While editing, taps no longer launch apps and the swipe gestures are paused so they don't get in the way.

### Notes
- Android still shows an install confirmation for every update.
