**Mat Launcher 1.5.0**

Multi-page apps, an always-on top bar, optional over-other-apps overlays, and a new look for Settings.

### New
- **Apps on every page.** When your home screen fills up, apps flow onto the next page. Pages are added automatically (up to 5) and no longer scroll endlessly.
- **Top bar on all pages.** The date and weather header stays in place across pages, like the dock. Switch it off in Settings → Top bar.
- **Control center over other apps (optional).** Swipe down from the top edge of any app. Pick a top-right or full-width swipe zone.
- **Lock screen over other apps (optional).** The Mat lock screen can appear on top of whatever app is open when the screen turns off.
  - Both overlays use Mat Launcher's accessibility service. It's off by default and reads nothing from your screen.
  - The overlay lock sits below Android's own system lock and doesn't replace it.
- **Update banner.** Settings opens with a colored banner showing your version in big white text. The color changes every release.

### Improved
- Restricted-settings help for phones with no ⋮ menu: an Allow button (with Shizuku), a copyable `adb` command, and a reinstall tip.
- Accessibility service added to the Permissions list.

### Notes
- Android still shows an install confirmation for every update.
- Wi-Fi, Bluetooth and airplane toggles still need the optional Shizuku app.
